🌸 OR Safety Intelligence V2.3 — ติดตั้ง Netlify

สำหรับ Windows · เปิดใช้งานเฉพาะฐานข้อมูลจริง ไม่มีโหมดทดลอง

สำคัญ: ไม่ใส่ข้อมูลผู้ป่วยจริงจนกว่าจะเปิด Google Login และทดสอบสิทธิ์การเข้าถึงเรียบร้อย

1. เปิด ZIP แล้วแตกไฟล์

คลิกขวาที่ ZIP → Extract All → เปิดโฟลเดอร์ OR_Safety_Intelligence_V2.3_FY2570. อย่าอัปโหลด ZIP ตรงเข้า Netlify Drop เพราะจะไม่ได้ตั้ง Backend ตามที่ต้องการ

2. เตรียม Node.js

ถ้าเครื่องยังไม่มี Node.js ให้ติดตั้งเวอร์ชัน LTS จาก nodejs.org แล้วรีสตาร์ท Terminal หรือเปิดเครื่องอีกครั้ง

3. รันไฟล์ Deploy

ดับเบิลคลิก DEPLOY_WINDOWS.bat ในโฟลเดอร์โปรเจกต์ สคริปต์จะทดสอบ → Build → เปิดให้ล็อกอิน Netlify → สร้างเว็บ เลือก Create a new site อย่าเลือกทับเว็บอื่น

หากนโยบายโรงพยาบาลห้ามรันไฟล์ .bat ให้เปิด Windows Terminal ในโฟลเดอร์นี้ แล้วสั่ง npm test, npm run build, npx netlify-cli login, npx netlify-cli deploy --build --prod ตามลำดับ

4. รับ URL แล้วตั้ง Google Cloud

หลัง Deploy จะได้ URL เช่น https://ชื่อไซต์.netlify.app. เปิด Google Cloud Console → สร้าง/เลือก Project → Enable Google Sheets API และ Google Drive API → สร้าง OAuth Client (Web application) → ใส่เว็บ URL ใน Authorized JavaScript origins (เฉพาะ origin ไม่มี path) → สร้าง Service Account ตามการอนุมัติของหน่วยงาน และแชร์ Google Sheets V2.3 ให้ service account (Editor)

Service Account JSON Key เป็นความลับ ห้ามส่งในแชต ห้ามใส่ใน ZIP หรือ GitHub

5. กำหนดค่าใน Netlify แล้ว Deploy ใหม่

Netlify → Site → Project configuration → Environment variables กำหนดค่าดังนี้ (เฉพาะ Functions):

  • GOOGLE_SHEET_ID = 1DgXv1S9_T5KMfolTlncbgqLh5EqbE0yNVGt-vC02BRM
  • GOOGLE_CLIENT_ID = ID ของ OAuth Web Client
  • GOOGLE_SERVICE_ACCOUNT_JSON = JSON Key ทั้งชุด ตั้งเป็นความลับ
  • ADMIN_EMAILS = อีเมลบัญชีผู้ดูแลที่อนุญาต
  • GOOGLE_DRIVE_FOLDER_ID = Private Drive folder สำหรับ PDF (ต้องมีสิทธิ์เขียน)
  • ALLOWED_GOOGLE_DOMAIN = กรอกเฉพาะต้องการบังคับ Google Workspace domain

จากนั้น Redeploy และเปิด https://ชื่อไซต์.netlify.app/api/?action=config ต้องตอบ configured: true แต่ยังต้องทดสอบ Sign In และอ่าน/เขียน Sheet

6. ทดสอบก่อนใช้งานจริง

ลงชื่อเข้าใช้ → สร้าง Incident ข้อมูลสมมติ → ตรวจแถวใน INCIDENTS → แก้ไข → ตรวจ AUDIT_LOG → สร้างรายงาน A4 → อัปโหลด PDF ทดสอบ (หากโฟลเดอร์ Drive พร้อม) → ลบแบบ Trash → ตรวจสิทธิ์ Viewer

ตรวจปัญหาที่พบบ่อย

ขึ้นข้อความระบบยังไม่พร้อม: ตรวจ Environment Variables, URL /api/?action=config และ Redeploy

Google Sign In ไม่ขึ้น: ตรวจ Authorized JavaScript origins และ Google OAuth Client ID

403: ตรวจ ADMIN_EMAILS หรือ USERS sheet และสิทธิ์ Google Workspace

โหลดข้อมูลไม่ได้: แชร์ Google Sheets V2.3 ให้ Service Account และตรวจ Sheets API

PDF Upload ไม่ได้: ตรวจสิทธิ์ private Drive folder (แนะนำ shared drive ขององค์กร)
